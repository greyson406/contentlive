> 最后更新：2026/05/22

> 📌 **关于文档状态**
> 本文档是按照系统设计编写的功能说明，描述的是产品的目标形态。受时间所限，部分功能目前尚未完整实现；后续将依据实际需求并通过持续迭代，逐步完善租户端的各项功能。文档也会随之同步更新。

## 按角色快速定位

**我是后台管理员（初次搭建系统）**
建议阅读顺序：[06 数据迁移](06-data-migration.md)（迁入旧数据）→ [01 员工与角色](01-staff-role.md)（拉团队进来）。

**我是内容 / 运营人员（内容上架与投放）**
建议阅读顺序：[02 采集到播放](02-collect-to-play.md)（把内容拉进来、加工好、投放到 App）→ [05 内容运营](05-ugc.md)（UGC 治理）。

**我是租户运营（日常运营）**
建议阅读顺序：[03 用户管理](03-user.md) → [04 会员等级](04-membership.md) → [05 内容运营](05-ugc.md)。

**我是审核人员（内容治理）**
直接阅读：[05 内容运营管理（UGC 管理）](05-ugc.md)。
